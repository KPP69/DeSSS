# DeSSS 前端设计规范

> 版本 1.0 · 2026-11-28
> 适用范围：`src/` 下的所有界面代码。改规范必须走 PR，不允许在页面里私自变通。

## 1. 原则

1. **数据优先**：界面是给人读数字的，不是展示布局的。先保证对齐、精度、可读。
2. **一个动作只有一个位置、一个词**。同一件事在不同页面长得不一样，就是 bug。
3. **不显示不可信的数**：实时数据只有三态，没有“旧值”。
4. **能用现有组件解决，就不新增组件**。
5. **少即是多**：主表 ≤ 7 列，记录表 ≤ 9 列；订单记录的「数量 / 已成交」合并一格；一屏只讲一件事。

## 2. 主题

- 只有两套：**暖色（默认）** 与 **深色**。
- 所有颜色来自 `tokens.css` 的 `--ds-*` 令牌；代码里禁止裸 hex / rgb / hsl。
- 对比度：标题 ≥ 10:1、正文 ≥ 6:1、元信息 ≥ 4.5:1、表单边界 3.0–3.5:1。
- 暖色分层用明度 + 极淡阴影；深色分层用三层底色 + 1px 线，不用阴影。

## 3. 骨架（每页相同）

```
标题栏   56px   页面名（全应用唯一一处）+ 控制台
功能栏   48px   页面级主操作（≤2 个，左对齐）；无操作时整条不渲染
内容头   40px   局部工具（分段 / 视图切换 / 刷新），右对齐
主体             表格或表单，独立滚动
```

- 页面内禁止再写页面名（不出现 `<h1>` 或标题组件）。
- 间距统一 8px 网格：16px 内边距、16px 列间距、24px 区块间距。

### 3.1 字号与圆角档位

字号只用四档，不自创中间值：

| 字号 | 用途 |
|---|---|
| 12px（`text-xs`） | 元信息（表头、辅助说明、徽标、延迟） |
| 13px（`text-[13px]`） | 正文（表体、按钮、输入框、表单、提示） |
| 15px（`text-[15px]`） | 紧凑数值（StatCard compact 值） |
| 16px（`text-base`） | 卡片标题、弹窗标题 |
| 18px（`text-lg`） | 页面名（标题栏，唯一一处） |

圆角只用三档：

| 圆角 | 用途 |
|---|---|
| 4px（`rounded`） | 小元素（Tooltip、下拉菜单、Checkbox、关闭按钮） |
| 8px（`rounded-lg`） | 控件（按钮、输入框、下拉触发器、分段控件） |
| 10px（`rounded-[10px]`） | 卡片（StatCard、Modal、DataTable 外框、页面分区卡片） |
| 全圆（`rounded-full`） | Badge |

## 4. 表格

### 4.1 列契约
写表之前先声明每列：类型、对齐、格式、空值。

| 类型 | 对齐 | 格式 | 空值 |
|---|---|---|---|
| 标识（账户、品种、来源） | 左 | 超长省略 + Tooltip | — |
| 数量、价格、盈亏、费率 | 右 | 固定小数位 + 等宽数字 | — |
| 枚举（方向、状态） | 居中 | 文字 + 颜色双重表达 | — |
| 时间 | 右 | `HH:MM:SS` | 永不空 |

- 单位进表头（`资金费 (%)`），不在单元格里重复。
- 数字一律 `tabular-nums`；每列小数位固定（按 tick / step）。
- 表头与数据列同对齐。
- 空值 `—`；真实的零写 `0`，不得用 0 冒充空。
- 行高：dense（表头 32px、数据行 32–36px）、normal（表头 36px、数据行 44–48px）；不允许逐行自定义行高。
- 粘性表头；最多冻结一列；960×640 下不得出现横向滚动。

### 4.2 数字格式（全应用统一函数）

| 场景 | 规则 |
|---|---|
| 价格 | 按 tick 小数位，去尾零 |
| 数量 | 按 step 小数位，去尾零 |
| 百分比 | 2 位小数，带 `+/−` |
| 金额 | 2 位小数，千分位 |
| 杠杆 | 整数（向下取整） |
| 极小值（< 1e-4） | 用 `1e-7` 形式，不自创写法 |

## 5. 动作位置

| 动作 | 位置 | 要求 |
|---|---|---|
| 新建 / 添加 | 功能栏 | 打开表单或弹窗 |
| 编辑 | 行内 | 打开表单 |
| 删除 | 行内，最后一位 | danger + 二次确认 |
| 刷新 / 重新读取 | 内容头右侧 | 统一 `RefreshButton`：loading + 失败 toast，成功不提示 |
| 保存 | 表单底部 | loading + 字段级错误 + toast |
| 启停 | 行内开关 | 停用需确认 |
| 平仓 / 保护 | 行内 | 二次确认 |

## 6. 状态与反馈

- 写操作：进行中禁用并 loading；失败 toast 显示后端原文；成功不提示。
- 查询：`PageState` 三态——loading / error（带重试）/ empty（带下一步动作）。
- 实时数据：三态——`载入中` / 实时值 / `无实时数据`。永不显示旧值。
- 危险操作：`ConfirmDialog`，确认按钮 danger，进行中双按钮禁用。
- Toast：右上角但位于标题栏下方，不遮挡控制台；最多 3 条；3 秒消失。

## 7. 文案

| 词 | 含义 |
|---|---|
| 刷新 | 重新读取当前数据（不承诺网络） |
| 同步 | 强制从交易所拉取一次 |
| 连接 / 断开 | 账户网络状态 |
| 启用 / 停用 | 策略是否运行 |
| 可用 / 暂停使用 / 未实现 | 策略类型状态 |

- 交易所一律全名：Hyperliquid / Entropy / Lighter / RH Lighter / AsterDEX / Arcus。
- 内部标识（`spread`、`spread_instant`）不得出现在界面。
- 错误提示显示后端原文，不吞、不改写。

## 8. 组件

只允许使用 `src/components/ui/` 下的组件：
Button、Input、Select、MultiSelect、Checkbox、Switch、Badge、Table、Modal、ConfirmDialog、Toast、PageState、StatCard、Tooltip、SegmentedControl、RefreshButton。

- SegmentedControl：视图 / 分段切换的唯一实现（radiogroup；←/→ 移动焦点，Enter / Space 选中）。
- RefreshButton：刷新的唯一实现（ghost + 图标 + 「刷新」；loading 转圈并禁用；Tooltip 用 §7 文案）。

- 页面内禁止原生 `<button>` / `<input>`。
- 禁止页面自定义颜色、行高、字号。
- 新组件必须先在规范里登记，再实现。

## 9. 交互

- 所有可交互元素 Tab 可达，有 `focus-visible` 焦点环。
- 行可点击是便利，必须有明确的键盘目标（Enter 打开）。
- 危险操作不与良性操作相邻。
- 不做数据入场动画；数值变化不闪烁。
- 实时值更新不改变列宽（固定列宽 + 等宽数字）。

## 10. 验收清单（可 grep / 可走查）

```
[ ] 页面名出现次数 = 1
[ ] 功能栏为空时不渲染
[ ] 页面内原生 <button>/<input> 数量 = 0
[ ] 裸 hex / rgb / hsl 数量 = 0
[ ] 页面直调 invoke( 数量 = 0
[ ] 数量列全部右对齐且 tabular-nums，小数位固定
[ ] 表头与数据列同对齐
[ ] 空值统一 —
[ ] 写操作 catch 内均有 toast
[ ] 危险操作均有 ConfirmDialog
[ ] 960×640 下无横向滚动
[ ] 两套主题下均无低对比度文本
```
